# Esep — финансовый помощник для малого бизнеса Казахстана

## О проекте
Esep (каз. «есеп» — счёт, учёт) — веб-сервис для ИП и малого бизнеса в Казахстане
(магазины у дома, кофейни, салоны, продавцы на Kaspi). Владелец загружает выписки
Kaspi / Halyk или вносит операции вручную, а сервис сам считает доходы, расходы,
прибыль и налог, напоминает о сроках и отвечает на вопросы через ИИ-помощника.

Это реальный продукт (учебный проект IITU, курс ECO6008), а не макет: всё, что
видит пользователь, должно работать с настоящими данными.

## Целевой пользователь
- ИП на упрощённом режиме, 1–5 сотрудников, оборот небольшой.
- Ведут учёт в тетради, Excel или никак; деньги приходят через Kaspi, Halyk и наличными.
- Главные боли: не знают реальную прибыль, путаются в налогах и сроках,
  смешивают личные и бизнес-деньги, нет времени на учёт.
- Пользуются в основном телефоном, поэтому дизайн mobile-first.

## Стек
- Next.js (App Router) + TypeScript (strict)
- Tailwind CSS + shadcn/ui, иконки lucide-react
- Supabase: Postgres, Auth (email + Google), Storage для файлов выписок
- next-intl: языки ru (по умолчанию), kk, en
- Recharts для графиков
- Импорт: pdf-parse (PDF выписки), xlsx / papaparse (Excel, CSV)
- ИИ: Claude API (@anthropic-ai/sdk) для категоризации операций и чата-помощника
- Email-напоминания: Resend; Telegram-бот (grammY) — во второй фазе
- PDF-отчёты: @react-pdf/renderer
- Деплой: Vercel; база в Supabase (free tier)
- Тесты: Vitest для логики (парсеры, расчёт налога), Playwright для ключевых сценариев

## Структура
```
app/[locale]/(marketing)/   лендинг, тарифы, о нас
app/[locale]/(auth)/        вход, регистрация
app/[locale]/(app)/         дашборд, операции, импорт, налоги, отчёты, ассистент, настройки
app/api/                    route handlers (импорт, ИИ, отчёты, cron)
lib/parsers/                парсеры выписок: kaspi.ts, halyk.ts, csv.ts
lib/tax/                    расчёт налогов, config.ts со ставками и сроками
lib/supabase/               клиенты (server, browser), типы
messages/                   ru.json, kk.json, en.json
supabase/migrations/        SQL-миграции
```

## База данных (основные таблицы)
- profiles: пользователь, язык, тариф
- businesses: название, тип (ИП / ТОО), налоговый режим, БИН/ИИН (необязательно)
- categories: доход / расход, название, цвет, системная или пользовательская
- transactions: business_id, date, amount (в тиынах, integer), type (income/expense),
  category_id, source (manual/kaspi/halyk/csv), description, counterparty, import_id
- imports: файл, банк, статус, количество операций
- reminders: тип (налог, аренда, зарплата), дата, повтор, канал (email/telegram)
- subscriptions: тариф, статус, дата окончания

Row Level Security включена на ВСЕХ таблицах: пользователь видит только данные своих бизнесов.

## Правила
- Деньги храним в тиынах (integer), показываем в ₸ с форматированием под локаль. Никаких float.
- Все тексты интерфейса берём из messages/*.json, без захардкоженных строк. Новый ключ
  добавляем сразу во все три языка.
- Ставки налогов, пороги и сроки лежат только в lib/tax/config.ts с комментарием-источником
  (kgd.gov.kz). Налоговый кодекс РК обновлён с 2026 года, поэтому значения обязательно
  проверить вручную. В интерфейсе пишем, что расчёт справочный.
- Каждый парсер выписки покрыт тестами на анонимизированных примерах из tests/fixtures/.
- Реальные выписки и персональные данные никогда не коммитим.
- Секреты храним только в .env.local; .env.example держим актуальным.
- Mobile-first: каждый экран проверяем на ширине 375px.
- После каждой фазы: `npm run lint`, `npm run typecheck`, `npm test`, затем коммит.
- Не добавляй новые библиотеки без необходимости; если добавил, кратко объясни зачем.

## Команды
- `npm run dev`: локальный сервер
- `npm run lint` / `npm run typecheck` / `npm test`
- `npx supabase db push`: применить миграции

## Тарифы (черновик, цены уточнить по интервью)
- Free: ручной ввод, до 50 операций в месяц, базовый дашборд
- Pro (~2 990 ₸/мес): импорт выписок, ИИ-категоризация, налоговый калькулятор, напоминания, PDF-отчёты
- Business (~5 990 ₸/мес): несколько бизнесов и сотрудников, Telegram-бот, ИИ-помощник без лимита

На первом этапе оплату не подключаем: тариф меняется вручную в админке. Платёжный
провайдер (Kaspi Pay, CloudPayments, ioka и т.п.) выбираем позже.
